# Стандарт фото товаров и устройств

Единый стандарт по образцу Amazon и Apple: покупатель видит товар, а не фотографию. Все карточки в каталоге, подборе по устройству, наборах, корзине и на главной выглядят одинаково: белый фон, объект в центре, одинаковые поля.

## Требования к изображению

| Параметр | Значение |
|---|---|
| Формат кадра | квадрат 1:1 |
| Фон | белый `#FFFFFF` (в хранилище — прозрачный, фон задаёт карточка) |
| Объект | вырезан, отцентрован, занимает 84 % большей стороны кадра |
| Поля | одинаковые со всех сторон, ~8 % |
| Ракурс | фронтальный или ¾, один товар в кадре, без рук, подставок, упаковки и посторонних предметов |
| Тени и отражения | без теней на фоне, допустима мягкая тень под объектом |
| Размер | мастер 1000–1600 px по стороне; варианты `thumb` 160, `card` 480, `large` 1200, `white` 1200 JPEG |
| Текст и логотипы | только те, что на самом товаре; никаких надписей, стикеров, водяных знаков |

Мастер хранится как WebP с альфа-каналом, поэтому один и тот же файл работает и на белой карточке, и на цветном промо-блоке, и на тёмном баннере. Вариант `white` — JPEG на белом фоне 1200×1200 — уходит в экспорт YML/CSV/XLSX и в маркетплейсы, где требуется именно белый фон.

## Как это работает в системе

1. **Загрузка через админку или импорт.** `storeImage` в `packages/domain/src/media/service.ts` при `IMAGE_NORMALIZE=true` прогоняет файл через `normalizeProductImage` (`media/normalize.ts`): опциональное удаление фона внешней командой, обрезка пустых полей, квадратный холст с одинаковыми полями, затем генерация вариантов.
2. **Удаление фона.** На сервере включается переменной `IMAGE_CUTOUT_COMMAND`, например `rembg i -m isnet-general-use {input} {output}` (нужен Python и `pip install "rembg[cpu]"`). Без команды изображение всё равно выравнивается по геометрии, а фон остаётся исходным — для фото, снятых сразу на белом, этого достаточно.
3. **Пакетная подготовка.** `tools/images/normalize.py` делает то же самое офлайн для папки с фото: `python tools/images/normalize.py ./src ./out`. Флаг `--flood` удаляет однотонный светлый фон заливкой от краёв (надёжнее нейросети для тёмных объектов на белом), `--largest` оставляет только главный объект.
4. **Демо-набор.** Все 133 seed-изображения прошли этот пайплайн; исходники лежат в `packages/database/seed-assets/images-original/`, результат — в `seed-assets/images/`. Источники и лицензии — `docs/IMAGE_CREDITS.md`.

## Что проверять вручную

Автоматическое удаление фона ошибается на тонких кабелях, прозрачных и стеклянных предметах, на тёмных объектах на тёмном фоне и на фото «в руках». Такие снимки лучше переснять по стандарту или подготовить в редакторе. Контрольный лист (`sheet`) удобно собирать из папки вывода и просматривать целиком перед загрузкой.
