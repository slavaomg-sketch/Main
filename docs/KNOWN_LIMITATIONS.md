# Известные ограничения и что осталось до публичного запуска

## Данные

- **Демо-изображения** взяты с Wikimedia Commons (см. `docs/IMAGE_CREDITS.md`). Часть фото — приближения (например, тонер HP показан фото другого тонера, ремешок Galaxy — фото часов). Перед запуском заменить реальными фото товаров (импорт из маркетплейсов подтягивает их автоматически при включённой опции «скачивать изображения»).
- **Характеристики устройств** — публичные данные производителей; значения, которые не удалось подтвердить точно, помечены `specsAreDemo` (Xiaomi 14, Canon EOS R50, GoPro HERO12, 70mai A800S, Tesla Model 3). На странице устройства показывается предупреждение.
- Отзывы в seed — демонстрационные, помечены как одобренные.
- Хранилище фото ограничено локальным диском; S3-драйвер объявлен, SDK подключается при настройке (`packages/domain/src/media/service.ts`).

## Интеграции (mock-режим до получения ключей)

- **Оплата**: `MockPaymentProvider` с локальной страницей `/mock-payment/[id]` и подписанным webhook. `YooKassaPaymentProvider` реализован по документации API v3, но не прогонялся с реальными ключами; тестовый магазин ЮKassa нужно проверить перед боем.
- **Доставка**: `MockDeliveryProvider` (фиксированные тарифы). `CdekDeliveryProvider` — заготовка по API v2 без интеграционного теста.
- **Уведомления**: `ConsoleNotificationProvider` пишет письма в лог. SMTP-провайдер требует подключить `nodemailer` и шаблоны.
- **Чеки 54-ФЗ**: `MockFiscalReceiptProvider`; адаптер АТОЛ — заготовка.
- **Маркетплейсы**: адаптеры Wildberries/Ozon/Яндекс Маркет написаны по публичной документации и не проверены с реальными токенами; обратная выгрузка цен/остатков не реализована.
- **LLM**: выключен (`DisabledLlmAssistant`); подключение Anthropic API — через `LLM_PROVIDER=anthropic`, интерфейс готов.

## Функциональность

- Сравнение товаров не реализовано (сочтено неоправданным для аксессуаров).
- MFA администратора: поля и точка проверки зарезервированы, TOTP не реализован.
- Восстановление пароля по email отсутствует (нет реального почтового транспорта).
- Обращения клиентов в поддержку (тикеты) — нет модуля; в карточке клиента есть пометка.
- Выдача «Мои устройства» для нескольких устройств одновременно ограничена первыми тремя дополнительными устройствами.
- Правила движка версионируются кодом; таблица `CompatibilityRule` хранит настройки, но UI редактирования параметров правил не сделан (только просмотр).
- Sitemap/robots: индексация выключена по умолчанию (`SEO_INDEXING_ENABLED=false`).
- Отчёт dry-run хранит до 5000 строк на файл.
- Изображения из импорта скачиваются синхронно в процессе применения (best-effort); для больших выгрузок стоит перенести в очередь воркера.

## Производительность

- Оценка совместимости для устройства считается «на лету» по всем активным товарам с кешем 60 с и предрасчётом в `CompatibilityRelation` воркером. Для каталога > 5 000 товаров нужно читать только предрасчитанные связи.
- Поиск построен на pg_trgm/FTS; `SearchProvider` позволяет заменить на внешний движок.

## До публичного запуска

1. Юридические тексты (оферта, политика) — проверить юристом; реквизиты компании в footer/страницах.
2. Ключи ЮKassa/СДЭК/АТОЛ/SMTP, тесты в песочницах, включить `SEO_INDEXING_ENABLED`.
3. Реальный каталог и фото через импорт; подтверждение совместимости специалистом (раздел «Автокандидаты»).
4. Домен, TLS, бэкапы по расписанию, мониторинг `/api/health`.
5. Нагрузочное тестирование поиска и страниц устройств на боевом объёме.
