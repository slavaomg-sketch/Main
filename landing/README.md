# Лендинг ЖК «Гранд Марина» (Хоста, Сочи)

Один файл `index.html` без зависимостей и сборки. Открывается локально двойным кликом, деплоится на любой статический хостинг (GitHub Pages, Netlify, Vercel, Timeweb).

## Что внутри

- Hero с формой захвата, статистика, CTA.
- Преимущества (6 карточек), расположение с картой-схемой и временем в пути.
- Планировки с фильтром по типам и кнопкой «узнать цену» на каждом лоте.
- Галерея (плейсхолдеры под рендеры), калькулятор доходности от аренды.
- Условия покупки, шаги сделки, FAQ, финальная форма, футер с дисклеймером.
- Модальное окно заявки, маска телефона, липкая CTA-панель на мобильных.

## Что заменить перед запуском

1. Телефон `+7 (862) 000-00-00` и почта — поиском по файлу.
2. Цены, метражи, этажи и сроки в секции «Планировки» — сейчас это ориентиры.
3. Плейсхолдеры галереи (`.g-item`) — на реальные рендеры: `background:url(...)`.
4. Отправку заявок — в `index.html` найдите `TODO` в скрипте и подставьте свой endpoint (CRM, Telegram-бот).
5. Ссылки на политику обработки ПД (`href="#"`).
