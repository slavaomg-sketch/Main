# Стиль карточек

Этот файл читает конвейер перед каждой карточкой и каждой картинкой. Правь свободно. Верхний блок yaml — параметры оформления надписей, ниже — правила текста и визуала словами.

```yaml
accent: "#FF6B35"        # цвет плашек, маркеров и акцентной линии
text_color: "#1A1A1A"    # цвет надписей
band: top                # где полоса с текстом на слайде: top или bottom
band_color: "#FFFFFF"    # цвет полосы под текстом
band_opacity: 0.82       # прозрачность полосы, 0–1
headline_size: 64        # размер заголовка слайда, px при 900×1200
line_size: 38            # размер тезисов
badge_size: 34           # размер плашки на главном фото
background: "clean white studio background, soft shadow"   # фон для генератора картинок, по-английски
font: ""                 # путь к своему ttf; пусто — Montserrat
```

## Текст

- Заголовок начинается с того, как товар ищут, а не с бренда.
- Описание: первый абзац отвечает «зачем мне это», дальше факты, потом сценарии, потом снятие сомнений.
- Без слов «уникальный», «премиальный», «лучший» без цифр за ними.
- Цифры и факты сильнее эпитетов: «держит тепло до −15 °C» лучше, чем «очень тёплая».

## Визуал

- Товар занимает не меньше 60% кадра на главном фото.
- Слайды: одна выгода на слайд, не больше трёх тезисов.
- Фон нейтральный, акцентный цвет только на плашках и маркерах.
