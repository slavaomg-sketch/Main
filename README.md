# ИНФОТРОН

Головоломка в духе **Supaplex**: Мёрфи прогрызает грунт, собирает инфотроны и уходит
в шлюз — пока сверху не прилетел зонк, а из-за угла не вышел патруль.

Чистый HTML + JavaScript: ни зависимостей, ни сборки, ни картинок — вся графика
рисуется кодом. Просто открой `index.html` в браузере.

```
git clone <репозиторий> && cd Main
xdg-open index.html          # или просто открой файл в браузере
```

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки / WASD | идти (и толкать зонк вбок) |
| **Space + направление** | «снап»: выесть клетку, не сходя с места |
| R | начать уровень заново |
| Esc / P | пауза и список уровней |

На телефоне снизу появляется экранная крестовина с кнопкой «СНАП».
Прогресс хранится в `localStorage`, уровни открываются по порядку.

## Мир и его правила

| Символ | Что это | Поведение |
|---|---|---|
| `.` | грунт | Мёрфи прогрызает его насквозь |
| `#` | стена | неразрушима даже взрывом |
| `=` | чип | как стена, но взрыв её дробит |
| `O` | зонк | падает, скатывается с круглого, толкается вбок в пустоту, давит насмерть |
| `*` | инфотрон | цель; тоже падает и скатывается |
| `E` | шлюз | открывается, когда собрано нужное число инфотронов |
| `S` | снипснак | идёт вдоль стен левой рукой, убивает при столкновении |
| `e` | электрон | идёт правой рукой; взрывается **инфотронами** |
| `o` | оранжевый диск | падает как зонк и детонирует при ударе; подрывает соседние диски |
| `^ > v <` | порт | пропускает только по стрелке, монстров не пропускает вовсе |

Тонкости, на которых держатся уровни:

* Зонк не падает, пока под ним что-то есть — **включая самого Мёрфи**. Стоять под
  камнем безопасно; смертельно из-под него уйти и вернуться.
* Толкать зонк можно только в **пустоту**, не в грунт. Дотолкав его до дыры в полу,
  вы роняете камень — так расчищают тупики.
* Монстр ходит по периметру пустого зала и не сворачивает внутрь, пока путь свободен.
  Середина зала — безопасное место, вход и выход — нет.
* Взрыв — квадрат 3×3: он рвёт грунт, чипы, инфотроны и монстров, но не стены.
  Взрыв электрона оставляет после себя инфотроны — иногда это единственный способ
  набрать нужное количество.

## Уровни

12 штук, каждый вводит одну механику и опирается на предыдущие:

1. Первый контакт · 2. Под камнями · 3. Пирамида · 4. Толкач · 5. Односторонние
6. Патруль · 7. Электроны · 8. Взрывное дело · 9. Шахта · 10. Лабиринт
11. Цепная реакция · 12. Финал

Уровни лежат в `levels/*.txt` обычным текстом:

```
name: Пирамида
needed: 3
hint: Зонк скатывается с круглого бока.
---
######################
#.M..................#
...
```

После правки карт нужно пересобрать `js/levels.js`:

```
npm run levels
```

## Проверка проходимости

Движок (`js/engine.js`) не знает про DOM и запускается в Node — поэтому каждый
уровень проверяется автоматически, а не «на глаз». Для каждого уровня в
`levels/solutions.json` хранится реальная последовательность ходов, которую
прогоняет тест:

```
npm test
```

Решения либо записаны вручную (уровни со взрывами), либо найдены автопилотом
из `tools/lib.js` — он ищет путь волной, обходит односторонние порты в последнюю
очередь и отбраковывает ходы, ведущие к смерти в ближайшие тики.

Отладка одного уровня в консоли:

```
node tools/play.js 7                       # показать стартовую карту
node tools/play.js 7 "D3 R6 r L2 .6"       # проиграть ходы (u/r/d/l — «снап», «.» — ждать)
node tools/play.js 10 --auto --trace       # прогнать автопилотом по шагам
node tools/verify.js 4 --save              # записать найденное решение в solutions.json
```

## Что где лежит

```
index.html          разметка, HUD, оверлеи
css/style.css       тёмная тема
js/tiles.js         словарь элементов и символов карты
js/engine.js        логика мира: гравитация, толкание, порты, монстры, взрывы
js/levels.js        СГЕНЕРИРОВАНО из levels/*.txt
js/sprites.js       процедурные спрайты (канвас, без картинок)
js/render.js        камера и интерполяция движения между тиками
js/input.js         клавиатура и экранное управление
js/game.js          игровой цикл, экраны, прогресс
levels/*.txt        карты уровней
levels/solutions.json  эталонные прохождения (регрессионный тест)
tools/              сборка уровней, автопилот, проигрыватель
```
