## Unit (tests/Unit)
- Smoke: загрузка конфигов, 8/8/12/6/2 сущностей, длины кругов.
- Spline: длина круга, ClosestProgress round-trip, wrap/delta, открытые сплайны.
- Checkpoints: порядок и круги, отказ телепорту, cap effective progress при срезке, невалидный финиш и откат
  чекпоинтов при движении назад, невозможное время сектора, Wrong Way.
- Placement: финишировавшие > круги > чекпоинты > дистанция; buckets предметов.
- Physics: три уровня дрифта, отсутствие награды за слабый дрифт, стартовый буст, руление от скорости,
  cap скорости, бездорожье; баланс: модификаторы героев в диапазоне, нормализация 0–100, разброс TopSpeed < 20%.
- Network: rate limiter, Validator (NaN/inf/типы/диапазоны/таблицы), диспетчер (маршрутизация, лимиты, state gate,
  Instance, неизвестные remote).
- Profile: миграции v1→v3, отказ более новой схеме, session lock, перехват просроченной блокировки без
  перезаписи, retry/backoff и temporary без записи default; награды идемпотентны, кривая уровней, unlock по уровню.
- Matchmaking: FormMatches (ожидание/bot fill, полное лобби, неделимые группы, TTL, режимы не смешиваются),
  Party/Queue (invite/accept/kick/leave, max 4, только лидер ставит группу, приватные режимы не в очереди).

## Integration (tests/Integration)
- QuickRace end-to-end: два игрока, профили, очередь → matchmaking → 8 участников → голосование (ранний
  резолв) → загрузка → loadout → grid → отсчёт (Perfect/Early старт по серверному времени) → 3 круга с предметами →
  Results → Rewards ровно один раз → сохранение → выход в лобби.
- Modes: Grand Tour 4 гонки без повторов трасс, очки, итоговая запись; Knockout выбывание по этапам; Time Trial
  без предметов с компактным призраком и выдачей рекорда; Team Race балансировка и командные очки; Core Clash
  ядра/recovery/таймер; Shard Rush потеря осколков/победитель; Private room валидация правил (mirror, laps, bots,
  speed class, allowed items, только владелец стартует); Practice.
- Disconnects: выход в середине гонки → DNF; выход после финиша → награда один раз; отказ DataStore →
  temporary-профиль, покупки запрещены, реальные данные не перезаписаны; провал teleport → возврат в очередь.
- Balance: 8 машин в диапазоне 7% времени круга, герои < 4%, Easy > Normal > Hard, все 6 трасс проходятся
  ботом за 57–64 с/круг.
