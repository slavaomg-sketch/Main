# Game Design

## Обещание
«Выбери героя и транспорт, освой дрифт, используй оригинальные гаджеты и побеждай друзей на трассах разных миров».
Гонка 3–4 минуты (3 круга по 55–65 с), матч с выбором 5–7 минут, Grand Tour из четырёх гонок ~20 минут.

## Герои (только модификаторы 0.9–1.1)
Nova Vale (Medium, баланс), Bolt Finch (Light, разгон), Bramble Rook (Heavy, устойчивость/бездорожье),
Mira Tide (Medium, управляемость), Kito Ember (MediumHeavy, импульс), Glint-7 (Light, дрифт/восстановление),
Tundra Moss (Heavy, сцепление), Saffron Quill (Medium, трюки/бусты). Разблокировки: по умолчанию 2, уровни 3/5/9,
валюта 1200/1500, достижение «три трюка за гонку». Тест держит разброс времени круга между героями < 4%.

## Транспорт (0–100 в UI, физика отдельно)
Comet Mk.I (карт, баланс), Finch Spark (трёхколёсный, разгон), Iron Yak (вездеход, вес), Tide Skimmer (ховер,
сцепление), Ember Fang (болид, максималка), Prism Pod (ховер, дрифт), Glacier Mule (багги, лёд/грунт),
Quill Runner (карт, бусты/трюки). Единая коллизионная коробка 6×3×9. Автоматический тест: разброс времени
круга всех машин < 12% (факт 7%), нет платных усилений.

## Физика ощущений
Raycast-подвеска, тяга с сужением к максимуму, боковое сцепление, руление от скорости (сильнее на малой),
дрифт с тремя уровнями заряда (1.0/2.2/3.6 с → +18/24/32% на 0.55/0.9/1.3 с), стартовый буст по серверному
времени (Early/Okay/Good/Perfect), трюк на трамплине, slipstream (1.2 с в конусе 20° ближе 28 studs),
поверхности (грунт, песок, лёд, мокрая, энергодорожка, опасная, буст-пад, трава, MagRail), стан 0.7/1.3 с
с иммунитетом 1.5 с, респавн к последней безопасной точке с неуязвимостью 2 с.

## Трассы
Neon Harbor Circuit (порт, мокрый участок, контейнерный шорткат), Cloudgarden Run (острова, ветровой тоннель,
три прыжка, небесный мост), Emberglass Caldera (гейзеры, закрывающийся шорткат, обрушивающийся мост,
энергетический тоннель), Frostbyte Foundry (лёд, прессы, конвейер, тёплая зона, ледяной жёлоб),
Sunken Observatory (течения, вращающиеся кольца, внутренняя галерея), Moonrail Metro (MagRail, крыши, плотный финал).
Арены: Prism Bowl, Scrapworks Arena.

## Предметы (сервер выдаёт по позиции/дистанции/кругам/активным сильным)
Nitro Cell, Pulse Disc, Hunter Wisp, Static Pod, Aegis Bubble, Gravity Drum, Blink Gate, Storm Crown (глобальный
кулдаун 45 с), Magnet Coil, Shockwave Horn, Phase Veil, Overcharge Pack. Energy Shards: до 10, +0.6%/шт (макс 6%),
теряются при попадании, конвертируются в валюту. Слоты Active/Reserve; при заполненных слотах выдача пропускается.
Скрытого выравнивания скорости реальных игроков нет; догоняющий эффект — предметы, slipstream, маршруты.

## Режимы
Quick Race, Grand Tour (4 гонки, очки 15/12/10/8/7/6/5/4/3/2/1/1, без повторов трасс), Time Trial (призрак,
компактная запись 10 Гц с фильтром движения), Private Custom Race (все правила валидируются), Knockout Circuit
(3 ворот, выбывает 25%), Team Race (2–4 команды, цвета с учётом дальтонизма), Core Clash (3 ядра, recovery 6 с),
Shard Rush (осколки, командный итог), Practice.

## Экономика
Финиш 60, место 120…10, чистая гонка 35, первый рекорд 40, осколки ×2, кубок 300…10, этапы knockout 25,
бой 110/40, XP 40 + 8/круг + позиция; уровень = 200·(L−1)^1.35. Косметика: окраски, следы, эмоции, сигналы,
декор — только за валюту. Лутбоксов нет.
