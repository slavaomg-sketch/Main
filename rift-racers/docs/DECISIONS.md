# Решения

| # | Решение | Причина |
|---|---|---|
| 1 | Проект живёт в `rift-racers/` внутри репозитория с Telegram-ботом | Бот не связан с игрой; не трогаем его код и CI |
| 2 | Studio MCP недоступен → Rojo-проект, headless-тесты в Lune, типизация luau-analyze | Не останавливать разработку; вся серверная логика тестируется без Studio |
| 3 | `.luau` вместо `.lua` | Современный стандарт Rojo/Studio |
| 4 | Один place (LocalMode) как vertical slice; Race Place через `TeleportAdapter` + флаг | Сервисы не привязаны к place |
| 5 | Процедурные трассы из сплайнов, а не ручные модели | 6 трасс за alpha, валидация данными, замена через контентный слой |
| 6 | Боты — кинематический `KartSim` на сервере, люди — raycast-физика на клиенте | Стабильный CPU для 12–24 ботов, одна физическая модель (`KartPhysicsModel`) для всех |
| 7 | Progress = arc-length на сплайне; чекпоинты равномерные, все обязательные; effective progress ограничен следующим чекпоинтом | Простая и защищённая от срезок формула позиции |
| 8 | MaxRacers = 12; 16/24 только в нагрузочном эксперименте | Требование ТЗ |
| 9 | Аудио и музыка — silent placeholders (`rbxassetid://0`) в `AudioConfig` | Без лицензии не подключаем чужие звуки; замена в одном файле |
| 10 | Rate limit по умолчанию 20/10 с; per-remote в схеме | Достаточно для намерений, режет спам |
| 11 | Grand Tour: сетка следующей гонки по обратным очкам | Стандарт жанра, честный старт |
| 12 | Knockout: ворота = конец каждого круга (4 круга, 3 этапа), выбывает 25% (мин 1), минимум 2 выживших | Понятно игрокам, показывается safe position |
| 13 | Hero modifier ограничен 0.9–1.1; тест держит разброс времени круга < 4% | Требование «герой не создаёт мету» |
| 14 | Selene не запускается офлайн (нужен API dump) | Ограничение среды; конфиг оставлен |
| 15 | Награда игроку, вышедшему после финиша, начисляется по provisional-ранжированию сразу при выходе | Нет потери прогресса, идемпотентность сохраняется |
